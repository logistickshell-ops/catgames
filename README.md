# Мурчальня

В сервисе оставлены пять основных кошачьих аркад: «Покорми кота», «Помой кота», «Башня котов», «Джампинг» и «Бег кота».

## Что обновлено

Игры получили более живую подачу: плавное движение котов, покачивание и вращение предметов, прыжковые squash/stretch-реакции, частицы при попаданиях и приземлениях, мерцающие звёзды, пузырьки, дождь, бегущие лапки и всплывающие игровые сообщения. На главной странице карточки появляются каскадно, эмодзи слегка покачиваются, hero-иллюстрация «дышит», а кнопки и игровые рамки реагируют на наведение и нажатие.

## Запуск

```sh
pnpm install
pnpm dev
pnpm build
```

Для Render Static Site:

- **Build Command:** `pnpm install --frozen-lockfile && pnpm build`
- **Publish Directory:** `dist`

## Мобильная версия

Сохранены safe-area, крупные touch-targets, адаптивный canvas, экранные кнопки для горизонтальных игр и отдельная оптимизация для коротких landscape-экранов.
