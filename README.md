# Мурчальня

Веб-сервис с **десятью** мини-играми про кота. Полностью клиентский: HTML5 Canvas + TypeScript + Vite,
без сервера и базы данных. Запускается как обычный статический сайт и сохраняет рекорды в `localStorage`.

## Игры

| # | Игра | Механика | Цель |
| --- | --- | --- | --- |
| 1 | Накорми кота | еда падает сверху, кот ловит её | 100% сытости за 60 с |
| 2 | Помой кота | стирание грязных пятен пальцем/мышью | 97% чистоты за 75 с |
| 3 | Башня из котов | качающийся кот падает по тапу на башню | 25 котов |
| 4 | Джампинг | кот прыгает вверх по платформам | 300 м высоты |
| 5 | Кот-бегун | бег вправо по платформам, сбор корма | 400 м дистанции |
| 6 | Пузырьковый кот | тап по летящим мыльным пузырям | 25 пузырей |
| 7 | Кот и клубки | кот ловит падающие разноцветные клубки | 20 клубков за 45 с |
| 8 | Лазерный кот | тап по движущейся красной точке | 15 попаданий |
| 9 | Кот-садовник | тап по цветам, чтобы поливать их | вырастить 8 цветов |
| 10 | Где кот? | найти кота, пока он меняет укрытие | 15 найденных котов за 40 с |

У всех игр есть крупная карточка «Играть», стартовые правила, HUD, экран победы/поражения,
кнопки «Ещё раз» и «В меню», локальный рекорд, пауза, звук, а также поддержка тача, мыши и клавиатуры.

## Запуск и деплой на Render

```sh
pnpm install
pnpm dev
pnpm build
```

Для **Render Static Site**:

- **Build Command:** `pnpm install --frozen-lockfile && pnpm build`
- **Publish Directory:** `dist`

Если Render не активирует pnpm автоматически:

```sh
corepack enable && pnpm install --frozen-lockfile && pnpm build
```

## Telegram Mini App

Официальный скрипт Telegram остаётся подключённым в `index.html`, а интеграция находится в `src/tg.ts`.
Она не занимает место на главной странице: приложение можно открыть как обычный статический сайт или
подключить в BotFather после публикации HTTPS-адреса.

## Структура

```
src/
├─ main.ts             точка сборки, тема, Telegram, роутер
├─ tg.ts               интеграция Telegram Mini App
├─ router.ts           history-роутер
├─ styles.css          дизайн-система и адаптив
├─ core/               цикл, canvas, ввод, звук, хранилище, векторная отрисовка
├─ ui/                 главная страница и оболочка игры
└─ games/              десять игр + реестр
```
