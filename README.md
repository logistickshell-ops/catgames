# Мурчальня

Веб-сервис с пятью мини-играми про кота. Полностью клиентский: HTML5 Canvas + TypeScript + Vite,
без сервера и базы данных. Запускается как обычный сайт и как **Telegram Mini App**.

## Игры

| # | Игра | Механика | Цель |
| --- | --- | --- | --- |
| 1 | Накорми кота | еда падает сверху, кот ловит её | 100% сытости за 60 с |
| 2 | Помой кота | стирание грязных пятен пальцем/мышью, пена и брызги | 97% чистоты за 75 с |
| 3 | Башня из котов | качающийся кот падает по тапу и встаёт на башню | 25 котов в башне |
| 4 | Джампинг | кот прыгает вверх по платформам, есть пружины и движущиеся | 300 метров высоты |
| 5 | Кот-бегун | бег вправо по платформам, прыжки через ямы и горшки | 400 метров дистанции |

Общее для всех игр: крупная кнопка «Играть» на карточке, стартовый экран с правилами,
экран победы и поражения с результатом, кнопками «Ещё раз» и «В меню», локальный рекорд,
пауза (кнопка, `P`, авто-пауза при потере фокуса), звук с отключателем.

## Управление

- **Тач:** палец ведёт кота (игры 1, 4), трение пальцем (игра 2), тап — действие (игры 3, 5).
- **Мышь:** то же самое мышью; в игре «Башня из котов» — клик.
- **Клавиатура:** `←` `→` или `A` `D` — движение, `Space` / `Enter` — действие, `P` — пауза, `R` — заново, `Esc` — меню.

## Адаптивность

- Мир игры фиксирован (480×720), канвас вписывается в доступную область с сохранением пропорций,
  а HUD и оверлеи масштабируются вместе с ним (размер шрифта рамки задаётся в JS).
- Учитываются `env(safe-area-inset-*)` и переменные Telegram `contentSafeAreaInset`.
- Экранные кнопки ◀ ▶ появляются только на устройствах с грубым указателем (тач).
- Отдельная раскладка для коротких ландшафтных экранов, тёмная тема — по теме Telegram или системы.

## Запуск

```sh
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # tsc --noEmit + сборка в dist/
pnpm preview
```

## Telegram Mini App

**1. Подключение официального скрипта** — в `index.html`, в `<head>`, до кода приложения:

```html
<script src="https://telegram.org/js/telegram-web-app.js" defer></script>
```

**2. Инициализация** — `src/tg.ts` выполняет стандартный набор вызовов и безопасно пропускает их
вне Telegram:

```ts
const tg = window.Telegram?.WebApp;
tg?.ready();                    // сообщаем клиенту, что приложение готово
tg?.expand();                   // разворачиваем на весь экран
tg?.disableVerticalSwipes?.();  // вертикальный свайп не закрывает мини-приложение
tg?.setHeaderColor('#FFF4E4');  // цвет шапки под тему сервиса
tg?.setBackgroundColor('#FFF4E4');
tg?.onEvent('viewportChanged', syncViewport);   // высота и safe-area в CSS-переменные
tg?.onEvent('themeChanged', applyTheme);        // светлая/тёмная тема клиента
```

Дополнительно сервис использует:

- `BackButton` — кнопка «назад» в шапке Telegram ведёт из игры в меню;
- `HapticFeedback` — отклик на победу, поражение и нажатия;
- `openTelegramLink` — кнопка «Поделиться» в блоке про Mini App;
- переменные `--app-height`, `--tg-content-*` — корректная высота и отступы под панели клиента.

**3. Публикация в BotFather**

1. Опубликуйте сайт и скопируйте публичный HTTPS-адрес.
2. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newapp` (или `/mybots` → *Bot Settings* →
   *Configure Mini App*) и укажите этот адрес.
3. Приложение откроется внутри Telegram и подхватит всю интеграцию автоматически.

Сервис работает и без Telegram: в обычном браузере модуль `tg.ts` не делает ничего,
а на главной странице показывается статус «Открыто в браузере».

## Структура

```
src/
├─ main.ts             точка сборки: тема, Telegram, роутер
├─ tg.ts               интеграция Telegram Mini App
├─ router.ts           history-роутер (/ и /game/:id)
├─ styles.css          дизайн-система и адаптив
├─ core/               цикл, сцена canvas, ввод, звук, хранилище, векторная отрисовка
├─ ui/                 главная страница и оболочка игры (HUD, оверлеи, пауза)
└─ games/              пять игр + реестр
```
