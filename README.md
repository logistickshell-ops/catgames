# Мурчальня

Веб-сервис с **пятнадцатью** мини-играми про котов. Полностью клиентский: HTML5 Canvas + TypeScript + Vite, без сервера и базы данных. Рекорды сохраняются в `localStorage`.

## Игры

| # | Игра | Цель |
| --- | --- | --- |
| 1 | Накорми кота | 100% сытости |
| 2 | Помой кота | 97% чистоты |
| 3 | Башня из котов | 25 котов в башне |
| 4 | Джампинг | 300 м высоты |
| 5 | Кот-бегун | 400 м дистанции |
| 6 | Пузырьковый кот | 25 пузырей |
| 7 | Кот и клубки | 20 клубков |
| 8 | Лазерный кот | 15 попаданий по точке |
| 9 | Кот-садовник | 8 цветов |
| 10 | Где кот? | поймать 15 котов, бегущих по площадке |
| 11 | Кот за мячиком | поймать 12 мячиков |
| 12 | Раскрась кота | создать 5 образов |
| 13 | Кот-лазер | лопнуть 16 шариков лучами из глаз |
| 14 | Три кота в ряд | собрать 12 троек |
| 15 | Зума с котами | лопнуть 20 котошариков |

Все обычные игровые коты переведены в чёрно-белый стиль в духе Felix. «Раскрась кота» специально оставляет палитру, чтобы пользователь мог менять образ героя.

## Мобильная оптимизация

Интерфейс учитывает safe-area, узкую ширину, высоту viewport, крупные touch-targets и landscape-режим. Canvas масштабируется без потери пропорций, игровые кнопки и заголовки не вылезают за экран, а для игр с горизонтальным управлением доступны экранные кнопки.

## Запуск

```sh
pnpm install
pnpm dev
pnpm build
```

Для **Render Static Site**:

- **Build Command:** `pnpm install --frozen-lockfile && pnpm build`
- **Publish Directory:** `dist`

Если Render не активирует pnpm автоматически:

```sh
corepack enable && pnpm install --frozen-lockfile && pnpm build
```

## Telegram Mini App

Официальный скрипт Telegram остаётся подключённым в `index.html`, интеграция находится в `src/tg.ts`. Блок с технической информацией убран с главной страницы: сайт можно открыть как обычный статический сайт или подключить в BotFather после публикации HTTPS-адреса.

## Структура

```text
src/
├─ main.ts             точка сборки, тема, Telegram, роутер
├─ tg.ts               интеграция Telegram Mini App
├─ router.ts           history-роутер
├─ styles.css          дизайн-система и адаптив
├─ core/               canvas, ввод, звук, хранилище, векторная отрисовка
├─ ui/                 главная страница и оболочка игры
└─ games/              пятнадцать игр и реестр
```
